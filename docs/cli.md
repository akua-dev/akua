# Akuapkg CLI reference

The command reference is generated from the CLI itself and published at
[docs.akua.dev/akua/cli](https://docs.akua.dev/akua/cli): every command, its
flags, the universal flags and the exit codes. Every structured error code is
documented at [docs.akua.dev/akua/errors](https://docs.akua.dev/akua/errors).

`akuapkg <command> --help` prints the same reference for the installed version.
The universal contract every command honors is in [cli-contract.md](cli-contract.md).
